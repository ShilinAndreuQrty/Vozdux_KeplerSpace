# KeplerSpace

Астрономическая лаборатория команды Vozdux для TulaHack 2026. На главной можно вращать карту Солнечной системы, менять дату и направление времени и переходить к датам астрономических событий. Каталог экзопланет показывает топ‑50 по учебной шкале приоритета для наблюдений и сравнивает орбиты планет в одной системе.

## Локальный запуск

Нужны Python 3.10 или новее и браузер. Распакуйте архив проекта или скачайте репозиторий и откройте в терминале папку с файлами main.py и requirements.txt. На Windows выполните в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --port 8010
```

В Linux и WSL:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn main:app --port 8010
```

Откройте [Солнечную систему](http://127.0.0.1:8010/), [каталог экзопланет](http://127.0.0.1:8010/exoplanets) или [задачу трёх тел](http://127.0.0.1:8010/three-body). В последнем разделе можно переключаться между 2D и 3D. Для режима 3D нужны WebGL и доступ к CDN с Three.js.

Остановить сервер можно через Ctrl+C. Если порт 8010 занят, замените его в команде и в адресе браузера, например на 8011.

### Что передавать команде

- Исходники, включая draft_math.py, requirements.txt, папки templates и static, а также data/catalog.json. В static уже лежат шрифты, а в data/catalog.json — снимок каталога NASA для офлайн-демо.
- Папку .venv каждый создаёт у себя. Файлы __pycache__ и личный data/catalog.local.json исключены из Git. Ключи API, Node.js, отдельная база и GPU для запуска не нужны.
- Интернет нужен для первой установки зависимостей и кнопки «Обновить» в каталоге. После установки сайт и каталог открываются локально со снимком данных.

## Данные и модели

- Кнопка «Обновить» загружает NASA PSCompPars через TAP. Успешная выгрузка сохраняется локально. При первом запуске доступен включённый в проект снимок от 15 ноября 2026 года по МСК. [Набор данных PSCompPars](https://doi.org/10.26133/NEA13)
- Приоритет для наблюдений учитывает радиус (до 30 баллов), близость полуоси к зоне обитаемости (до 30) и долю оборота в зоне (до 40). Вес факторов задан проектом. При неизвестном эксцентриситете вклад доли отсутствует. Для расчётного радиуса показывается отметка «Оценка». [Границы ExoColumn](https://arxiv.org/abs/2611.09475) · [Радиусы и состав](https://arxiv.org/abs/1407.4457)
- Карточка показывает полноту данных, происхождение параметров и классический ESI. Полный ESI требует температуру поверхности. В PSCompPars есть равновесная температура, поэтому включённые карточки показывают доступные компоненты и перечисляют недостающие. [Методика ESI](https://phl.upr.edu/projects/earth-similarity-index-esi)
- На главной расстояния сжаты для обзора всей системы, размеры спрайтов увеличены. Камера проецирует трёхмерные орбиты на Canvas 2D. Положения вычисляются по элементам на 1800–2050 годы. Для Земли используется барицентр системы Земля–Луна. Даты событий служат точками входа в модель, а пунктир соединяет Землю с планетами выбранного события. Для расчёта видимости нужен местный горизонт. [Приближённые положения JPL](https://ssd.jpl.nasa.gov/planets/approx_pos.html) · [Окна наблюдений NASA](https://science.nasa.gov/solar-system/skywatching/planetary-alignments-and-planet-parades/)

Для обновления из терминала запустите `python archive.py` тем же интерпретатором, которым запускаете сайт, и перезапустите сервер.
